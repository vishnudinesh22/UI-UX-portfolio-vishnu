# Vishnu Dinesh: UI/UX portfolio

React + Vite. Run `npm install`, then `npm run dev` (http://localhost:5173) or `npm run build`.

- All text and links live in `src/content.js`. Anything starting with `TODO` shows as a gold italic placeholder.
- To add a prototype link to a project, set its `link` field to a full https URL.
- Deploy: push to GitHub and import in Vercel (framework: Vite), or run `npx vercel`.
- Then set `uiuxPortfolioUrl` in the game's `src/portfolioConfig.js` to the new URL.
